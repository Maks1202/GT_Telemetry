# LAP-PIN-TRACK-001

Статус: закрыта. Влита в `main`, ветка удалена. Версия `0.19.0`.

Когда на гонке трасса закреплена, имя этой трассы должно попадать в сохранённый круг. Сейчас при финише сервер снова ищет трассу по последней точке; если машина вне полотна, в круг пишется «неизвестно», и при просмотре круга синей ленты нет.

Клиент сообщает серверу закреплённое имя (и сбрасывает его при откреплении). При финише круга: если есть закреплённое имя — сохранить его; иначе — как сейчас, `match_track` по последней точке. «Старт»/«Стоп» сами по себе закрепление не меняют.
