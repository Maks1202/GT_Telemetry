# LAP-VIEW-3D-001

Статус: закрыта. Влита в `main`, ветка удалена. Версия `0.20.0`.

Только страница просмотра круга. В углу блока PATH — переключатель **2D / 3D**.

**Общее (оба режима):** лента трассы **серая** (не синяя). Цветная траектория по газу/тормозу и маркер авто остаются. Гонка и редактор трасс не трогать.

**3D:** Three.js `three@0.186.1` (или новее patch той же minor, если npm отдаёт только его). Сцена с высотой полотна (Y краёв). Орбита, зум; по умолчанию фокус в центре трассы. Клик по маркеру авто — фокус на авто, зум относительно этого фокуса. Маркер авто — 3D: к треугольнику добавить вершину над основанием (объёмная пирамидка). Рендер не вхолостую: только при взаимодействии с канвасом и при смене выбранного маркера (клик по траектории или по графику газа/тормоза). В блоке канваса показать Stats/FPS.

Замок «без Three.js» для этой задачи снят.
