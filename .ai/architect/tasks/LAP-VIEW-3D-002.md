# LAP-VIEW-3D-002

Статус: разрешена. Ветка `task/LAP-VIEW-3D-002-track-light`.

Правка 3D на просмотре круга (не новая фича).

1. **Модель трассы:** убрать «глюки» ленты — ненадёжное pairing inner[i]/outer[i] после независимого stride. Пересобрать mesh: одинаковая дискретизация по длине дуги, согласованное направление краёв (при необходимости развернуть outer), корректные треугольники полосы, нормали. Лента остаётся серой.
2. **Свет + форма маркера:** добавить освещение сцены (ambient/hemisphere + directional). Маркер авто — материал с затенением (Lambert/Standard), не MeshBasic, чтобы пирамидка читалась объёмом. Рендер по-прежнему on-demand.

Только `apps/web` lap 3D. Гонка/редактор/сервер не трогать.
