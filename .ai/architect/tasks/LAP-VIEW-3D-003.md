# LAP-VIEW-3D-003

Статус: разрешена. Ветка `task/LAP-VIEW-3D-003-station-ribbon`.

Правка 3D-полотна на просмотре круга (не фича).

Убрать сшивку `inner[i]`–`outer[i]`. Новая геометрия:

1. Края inner/outer остаются источником.
2. Построить ось (центрлайн) между краями.
3. Шагать по оси равными станциями.
4. На каждой станции поперечник: пересечение (или ближайшие точки) с inner и outer.
5. Соседние станции → прямоугольник (квад) → два треугольника → mesh полотна.
6. Серые края линиями как сейчас; материал полотна серый, lit по возможности; on-demand render сохранить.

Только lap 3D (`lapView3d.ts` и при необходимости мелочи). Гонка/редактор/сервер не трогать.
