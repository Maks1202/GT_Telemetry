# ADR-001. Технологический стек GT Telemetry

- Статус: предложено, ждёт утверждения владельца
- Дата: 2026-10-18
- Область: первая локальная версия

## Контекст

Нужно локальное веб-приложение для Gran Turismo 7 на PS5. Два равных приоритета первой версии: живая телеметрия во время гонки и автоматическая запись кругов, которая переживает перезапуск.

Папка `legacy/gt7dashboard` — пример того, как читать телеметрию GT7. Это не продукт и не место для новых экранов. Её не меняем. 18 октября 2026 с консоли `192.168.0.136` по этому же протоколу газ в пакетах доходил от `0` до `100`. Тормоз педалью ещё не проверялся.

## Решение

Одно локальное приложение, без микросервисов и без Docker.

| Часть | Выбор |
| --- | --- |
| Язык приёма и записи | Python 3.12 или новее. На этом Mac установлен 3.14.5, отдельный 3.12 не требуется |
| HTTP | FastAPI, только локальный адрес |
| Поток в браузер | WebSocket |
| Интерфейс | TypeScript, React, Vite. Открывается в браузере на том же компьютере |
| Графики | библиотеку не выбирать, пока не понадобится сравнение кругов |
| Учёт | SQLite: сессии, круги, метаданные |
| Телеметрия круга | JSONL, дописывание по мере пакетов |
| PostgreSQL | нет |
| Контейнеры | нет |

Адрес PS5 задаётся конфигурацией, в код не зашивается. На этой машине широковещательный адрес `255.255.255.255` не работает (ошибка 49).

Логические части одного процесса:

1. Telemetry Ingest — UDP.
2. Protocol Decoder — проверка, расшифровка, поля пакета.
3. Telemetry State — последнее состояние машины и сессии.
4. Lap Recorder — границы круга и запись.
5. Storage — SQLite и JSONL.
6. Realtime API — HTTP и WebSocket.
7. Web UI — живая панель и история.

Приём и запись не ждут браузер. WebSocket отдаёт снимок с ограниченной частотой. Медленный клиент не копит очередь и не тормозит приём.

## Почему так

Протокол уже проверен на Python. Перенос расшифровки на другой язык ничего не даёт первой версии. FastAPI и WebSocket разделяют приём и экран без второго процесса. React и Vite дают обычный локальный интерфейс. SQLite хранит итоги кругов между запусками. JSONL пишет точки по мере поступления: уже записанный хвост файла остаётся после обрыва процесса. Оба приоритета v1 закрываются без карты трассы и без отдельной базы.

## Протокол, который уже подтверждён

Повторять поведение, не копируя файлы из `legacy/`:

- Heartbeat: байт `A` на UDP-порт `33739`.
- Приём: UDP-порт `33740`.
- Расшифровка Salsa20, ключ `Simulator Interface Packet GT7 ver 0.0`, проверка magic `G7S0`.
- Газ: байт `0x91 / 2.55`. Тормоз: байт `0x92 / 2.55`.
- В том же пакете старый декодер читает скорость, обороты, передачу, номер круга, время последнего круга, флаги паузы и гонки, идентификатор машины.

Наблюдение 18 октября 2026: около 60 пакетов в секунду, газ доходил до 100 процентов, тормоз в этой проверке оставался 0.

## Лицензия

В `legacy/gt7dashboard/LICENSE` лежит текст GNU GPL-3. Файла `LICENSE.txt`, на который ссылается `pyproject.toml`, нет. Заголовков лицензии в модулях нет.

Пока владелец не выберет лицензию GT Telemetry, код из `legacy/` в новое приложение не переносится и не импортируется. Допустимо заново написать приём по уже проверенным смещениям и по публичному описанию пакета. Если владелец выберет GPL-3 для всего приложения, перенос с сохранением лицензии и указания автора можно разрешить отдельным решением.

## Последствия

- Задача `LIVE-THROTTLE-BRAKE-001` (правка экрана Bokeh внутри legacy) снята. Ветка не создавалась.
- Первая будущая задача, ещё не разрешённая: одна страница `Live Telemetry` с газом и тормозом. Запись кругов в неё не входит.
- Номер версии остаётся `1.0.0`, пока не изменится код продукта.
- Порты v1: UDP `33739` и `33740` для консоли; HTTP и WebSocket только на localhost.
- Код не писать, пока владелец не утвердит этот ADR и план.

## Вне этого решения

Карта трассы, секторы, расширенные графики, PostgreSQL, Docker, публикация API в интернет, смена протокола на другой язык.
